# 架构

身份 → 协调计划 → 代码合规检查 → 四域只读工具 → 证据 → 确定性一致性/规则汇总 → 返回或人工审核。

先订单读取关联上下文，再按依赖并行执行专家，不是四域无条件并行。真实MCP SDK使用stdio握手及list/call；不是任意HTTP改名。

知识采用CPU嵌入、BM25/RRF及精确/Milvus后端；规则知识不当作实时业务事实。缺失与不确定状态不推导唯一财务原因。

每次检索800ms含主路600ms、备路150ms、余量50ms，不是全图预算。进程隔离取消、熔断和准入属于单进程范围。

SQLite工单及官方SqliteSaver支持interrupt/Command和已提交结果恢复。审核节点不调用模型或改业务，不承诺任意专家内部恢复。

应用/历史脚本保持原已验收字节；公开tools路径和分发配置单独适配，不能把发布锁当作新公开分发容器验收。
